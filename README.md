# デュエマ オンライン (身内用)

友達同士でデュエル・マスターズ / デュエパーティーをオンライン対戦するための非公開サイトです。
GitHub Pages (サイトの置き場所) + Firebase 無料プラン (ログイン・デッキ保存・リアルタイム対戦) で、**完全無料** で動きます。

## できること

- **オンラインデュエマ**: パスワードでルームを作って1対1で対戦。3人目以降は観戦 (対戦中に入った人は自動で観戦)。CPU戦も可能。
  - ルール設定: 通常ルール / 殿堂ゼロ、アドバンス / オリジナル
- **オンラインデュエパ**: 2～5人で対戦。全員が対戦/観戦を選べる。CPUの追加・削除が可能。
- **デッキ編成**: 名前・テキスト・種族・文明・コスト・パワー・カードの種類で検索。超次元・超GRゾーン対応。
  - レギュレーション違反は保存時に警告 (保存はできる)。違反デッキはルームで選択不可。
  - ランダム生成 (違反しない範囲で完全ランダム) / 王道プリセット4種 (攻め・守り・技・力) の挿入
- **設定**: プレイヤー名、スリーブ画像、プレイマット画像 (アップロードした画像を自動で縮小)
- **CPU**: 自分が作ったデッキ・プリセット・ランダムデッキから選んで対戦相手にできる

### ルール処理について (ハイブリッド方式)

| 自動で処理 | 手動で処理 (カードをクリックして操作) |
|---|---|
| ターン進行、ドロー、マナチャージ、コスト・文明の支払い、召喚酔い | 誘発型能力のうち、対象選択や条件判定が必要な効果の中身 (発動自体は自動) |
| 「出た時」「攻撃する時」「相手が呪文を唱えた時」などの誘発型能力の発動 (下記) | 常在型能力 (コスト軽減・攻撃できない条件など) |
| 攻撃・ブロック・バトル・シールドブレイク・ダイレクトアタック | 進化元・コスト軽減などの特殊な条件 (「支払いを調整して出す」で対応) |
| S・トリガー、G・ストライク、ブロッカー、スピードアタッカー、マッハファイター、W/T/Q/ワールド・ブレイカー、スレイヤー、パワーアタッカー | |
| 革命チェンジ、侵略、ニンジャ・ストライク、ツインパクト (面の選択)、進化、EXライフ、チャージャー | |
| 山札切れ・パワー0以下の破壊、デュエパのパートナー・脱落処理 | |

### 誘発型能力の自動発動

カードテキストを解析して、次のタイミングで能力を **自動で発動** します (発動するとゲームは解決を待ちます)。

- 出た時 / 召喚した時、自分の(他の)クリーチャー・相手のクリーチャーが出た時
- 攻撃する時、攻撃された時、ブロックした時・された時、ブロックされなかった時、バトルする時、バトルに勝った時
- 破壊された時(される時)、バトルゾーンを離れた時、墓地に置かれた時、シールドをブレイクした時、自分のシールドがブレイクされた時
- 自分/相手が呪文を唱えた時、自分/相手のターンのはじめ・終わり、クロスしたクリーチャーが攻撃する時
- 呪文を唱えた時の呪文自体の効果

解決のしかた:
- 条件や選択がない単純な効果 (例: 「出た時、カードを1枚引く」) は **自動で実行**
- 対象を選ぶ効果・任意の効果は、右側のパネルに能力のテキストとボタン (「相手のクリーチャーを1体破壊 (対象を選ぶ)」など) が表示されます。ボタンかカードのクリックで処理して「処理完了」を押します
- CPU はすべて自動で処理します

## セットアップ (最初に1回だけ・約15分)

### 1. GitHub にアップロード

1. GitHub で新しいリポジトリを作る (例: `duema-online`)。
   - **注意**: 無料プランで GitHub Pages を使うにはリポジトリを **Public** にする必要があります。
     サイトのURLを知らない人は辿り着けず、検索エンジンにも載らない設定 (noindex) にしてあります。
     さらに下の「遊べる人を制限する」を設定すれば、友達以外はログインしても何もできません。
2. このフォルダの中身を push する:
   ```bash
   git remote add origin https://github.com/<あなたのユーザー名>/duema-online.git
   git push -u origin main
   ```
3. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
4. 数分待つと `https://<あなたのユーザー名>.github.io/duema-online/` で公開されます (Actions タブで進行状況を確認できます)。

### 2. Firebase プロジェクトを作る (無料・クレジットカード不要)

1. https://console.firebase.google.com/ を開いて Google アカウントでログインし、「プロジェクトを作成」。
   (Google アナリティクスはオフで OK)
2. **Authentication** → 始める → ログイン方法で **Google** を有効にする。
3. **Authentication → 設定 → 承認済みドメイン** に `<あなたのユーザー名>.github.io` を追加。
4. **Realtime Database** → データベースを作成 → 場所は `asia-southeast1 (シンガポール)` など → **ロックモード** で開始。
5. Realtime Database の **ルール** タブを開き、このフォルダの `database.rules.json` の中身を貼り付けて「公開」。
6. プロジェクトの設定 (⚙) → マイアプリ → ウェブアプリ (`</>`) を追加 → 表示された `firebaseConfig` の値を
   `src/firebaseConfig.ts` に貼り付ける (`databaseURL` も忘れずに。Realtime Database の画面上部に表示されている URL です)。
7. 変更を commit して push すると、オンラインモードで公開されます。

> `firebaseConfig` の値 (apiKey など) は公開されても問題ない値です。アクセス制御は `database.rules.json` で行っています。

### 3. 遊べる人を制限する (推奨)

`database.rules.json` の `"auth != null"` を、友達のメールアドレスだけ許可する条件に置き換えて Firebase に貼り直します。

```
auth != null && auth.token.email.matches(/^(you@gmail\.com|friend1@gmail\.com|friend2@gmail\.com)$/)
```

## 無料枠の目安

Firebase Spark (無料) プラン: 同時接続100人 / データ保存1GB / ダウンロード月10GB。
対戦は「アクションだけ」を送る方式なので、友達同士で遊ぶ分には十分に収まります。
スリーブ・プレイマット画像は縮小して保存しています (スリーブ約30KB、プレイマット約200KB)。

## カードデータの更新

カードデータは公式カード検索 (https://dm.takaratomy.co.jp/card/) と殿堂レギュレーションのページから取得しています。
新弾が出たり殿堂が改定されたら、以下を実行して commit / push してください (Node.js が必要)。

```bash
npm install
npm run cards:update
```

- イラスト違い・再録の同名カードは除外しています。
- カード画像は公式サイトの画像を直接表示しています (このリポジトリには含めていません)。
- デュエパのデッキ構築ルール (60枚・ハイランダー・パートナー・プレ殿/超次元/GR/ゲーム開始時のカード使用禁止) は公式ルールに基づいています。
- プリセットデッキは `data/presets.json` (カード名と枚数) で編集できます。

## 開発用

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # ルールエンジンのテスト (CPU同士の対戦シミュレーション)
```

`src/firebaseConfig.ts` が空のときは **ローカルモード** で動きます。同じブラウザのタブ同士で対戦でき、タブごとに別のプレイヤーになります。

## 構成

- `src/engine/` ルールエンジン (決定的。全員が同じアクション列を適用して同期)・CPU・効果アシスト
- `src/lib/` カードDB・キーワード能力の解析・デッキのレギュレーション判定・検索
- `src/backend/` Firebase / ローカルモードの切り替え
- `src/pages/`, `src/game/` 画面
- `scripts/` カードデータ取得・変換スクリプト

カード名・テキスト・画像の著作権は株式会社タカラトミー等の権利者に帰属します。個人的な非公開利用のためのツールです。
