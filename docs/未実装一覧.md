# まだ自動処理できない能力の一覧

2026/10/21 時点。全11,836種類のカードテキストを解析器にかけて、解析できなかった文を集計したもの。

- 「未解析の数」は、解析できなかった行・文の延べ数です（数字だけが違う似た文はまとめて数えています）。1枚のカードに複数あれば複数回数えます。
- ここにある能力も、対戦画面の手動操作（カードの移動・タップ・パワー変更・裏返し・重ねる など）で処理できます。
- 再集計: `COVER=1 npx vitest run src/rules/coverage.test.ts`（結果は `coverage-miss.log` と `coverage-miss.log.static`）

## 補足

- 「N枚より多くデッキに入れることができる」はゲーム中の能力ではなく、デッキ編成の枚数チェックで対応済みです。
- ドロン・ゴー、革命0トリガー、革命トリガーは、注釈の解析で処理できているため上の表に入っていません。
