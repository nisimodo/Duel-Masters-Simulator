## 2. 名前のない効果文で多いもの

| 種類 | 例 |
|---|---|
| シールドの下に重ねる（城・要塞化） | 「山札の上から1枚目を裏向きのまま、自分のシールドいずれかの下に置く」 |
| 相手が置き場所を選ぶ | 「相手はそれを山札の上か下に置く」 |
| 「離れない」「とどまる」の条件つき | 「次の自分のターンのはじめまで、このクリーチャーは離れない」「そのパワーがNより大きければ、離れるかわりにとどまる」 |
| 手札を見せて軽減 | 「自分の手札にある多色カードを1枚相手に見せてもよい」の後の効果 |
| ブレイクの置換 | 「相手はそのシールドを手札に加えるかわりに墓地に置く」 |
| 回数・繰り返し | 「次の能力をN回行う」「真上の能力をもう1度使う」 |
| 特殊な勝敗・ターン | 「支払えなければ、自分はゲームに負ける」「ターンの残りをとばす」 |

このほかに、1〜4枚のカードにしか出てこない文が数千種類あります。

## 補足

- 「N枚より多くデッキに入れることができる」はゲーム中の能力ではなく、デッキ編成の枚数チェックで対応済みです。
- 置換効果の「〜してもよい」(例: 破壊されるかわりに他のクリーチャーを破壊してもよい) は、払える時は自動的に払います。
- 「そのターンにまだ攻撃を受けていない場合、可能ならこのクリーチャーを攻撃する」は、「まだ攻撃を受けていない」条件を省略しています。
